# Syllogic Labs

The intelligent operating system for modern hospitality and enterprise.

A cinematic product site for **Costora**, **Menura**, **EasyRoom**, and **Syllogic Ledger** — standalone modules that fuse into one operating fabric.

## What you can do

- Toggle **Standalone / Synced** and watch Costora costing push live prices into Menura
- Explore each module with a working demo
- Scope a bespoke brief (F&B group, boutique hotel, multi-property)
- Request a discovery call

## Stack

TanStack Start · React 19 · Tailwind CSS v4 · Motion
